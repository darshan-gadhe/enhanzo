# ASO Keyword Bank — Enhanzo: AI Photo Enhancer

**2728 unique keywords**, deduplicated and grouped by search intent.

Two corrections since the first version, both about accuracy rather than
volume:

- **Added a background-removal cluster** (181 terms). Remove BG
  ships now and the bank had nothing for it.
- **Removed 30 terms** targeting watermark removal and 8K
  export. The app does neither: it has never applied a watermark, and
  inputs are capped to the model's GPU budget so a typical photo tops out
  around 6K. Ranking for a promise you cannot keep buys an install and
  loses a user, and retention feeds back into rank.

## Read this first

**Google Play has no keyword field.** It indexes only three things:

| Field | Limit |
|---|---|
| Title | 30 chars |
| Short description | 80 chars |
| Full description | 4000 chars |

This list is **research input, not something to paste into the listing.** Pasting
even a fraction of it would break Play's spam policy ("Store Listing and Promotion")
and can get the listing suppressed or rejected. 2500 terms is roughly 20,000
characters — five times the entire description limit.

Use it to:

1. **Pick the ~20-30 terms** worth earning, and write them naturally into the title,
   short description and first 2 lines of the full description (what Play weights most).
2. **Feed Google Play Console → Store performance → search terms** to see which of
   these you already rank for, then rewrite around the winners.
3. **Fill Apple's 100-character keyword field** verbatim if you ever ship to iOS —
   that field does exist, and this is exactly the input it needs.
4. **Seed Google Ads / ASA campaigns**, where long lists genuinely are used.
